# Примеры к лекциям на Jupyter

Все примеры написаны на одной небольшой библиотеке [`kinlib.py`](kinlib.py): только `numpy`, `scipy` и `matplotlib`, без робототехнических пакетов, чтобы каждую формулу лекции можно было найти в коде.

| Файл | К какому занятию | Что внутри |
|---|---|---|
| [`ПЗК_и_ОЗК_на_Python.ipynb`](ПЗК_и_ОЗК_на_Python.ipynb) | 1–3 | исходный ноутбук курса: классы `Frame`, `RobotSerial`, `RobotTrajectory` «с нуля», прямая и обратная задачи для шестизвенника, траектория |
| [`Демо_Занятие_02_положение.ipynb`](Демо_Занятие_02_положение.ipynb) | 2 | матрицы Денавита — Хартенберга, ПЗК, рабочая зона 2R и 6R, показатель Ли — Янга, коэффициент сервиса, ветви ОЗК, сходимость итерационной ОЗК, цепочка близких целей |
| [`Демо_Занятие_03_скорость.ipynb`](Демо_Занятие_03_скорость.ipynb) | 3 | $\dot R = \Lambda R$, якобиан по столбцам и численно, вырожденные конфигурации, ОЗК о скорости у особой точки, избыточный 3R, сфера — эллипс — многоугольник скоростей, мобильность, приемистость |

Ноутбуки сохранены выполненными: рисунки видны прямо на GitHub. Ячейки «Интерактив» с ползунками работают только при живом запуске.

## Запуск

```
pip install numpy scipy matplotlib jupyter ipywidgets
jupyter notebook
```

Запускайте ячейки сверху вниз; первая ячейка подключает `kinlib`.

## Что умеет kinlib

| Объект | Назначение |
|---|---|
| `Frame` | однородная матрица 4×4: произведение, обращение, построение по параметрам Денавита — Хартенберга (`from_dh`, `from_dh_modified`), по углам Эйлера, кватерниону |
| `RobotSerial(dh, joint_types='RRP…')` | разомкнутая цепь по таблице `d, a, alpha, theta0`; вращательные (`R`) и телескопические (`P`) сочленения; `forward`, `axis_frames`, `jacobian`, `inverse_numerical` (методы `jac_pinv`, `jac_dls`, `jac_t`, история сходимости), `inverse_position`, `workspace_random`, `draw` |
| `RobotTrajectory` | интерполяция между положениями в пространстве сочленений (`p2p`) и по прямой (`lin`) |
| `fk2r`, `ik2r`, `jac2r`, `fk_planar`, `jac_planar`, `draw_arm2d` | плоские двух- и многозвенники |
| `workspace_2r`, `area_from_points`, `service_map_3r`, `service_coefficient_3r` | рабочая зона и коэффициент сервиса |
| `skew`, `vee`, `jacobian_numeric` | кососимметрическая матрица $\Lambda(\boldsymbol{\omega})$ и численная проверка якобиана |
| `polygon_image`, `ellipse_image`, `sphere_radius`, `manipulability` | области допустимых скоростей и меры манипулятивности |
| `make_ur()` | шестизвенник с размерами типа UR10 для примеров |

Порядок строк якобиана в `RobotSerial.jacobian` — $[\mathbf{v};\ \boldsymbol{\omega}]$ (сначала линейная скорость). В учебнике порядок обратный; метод `jacobian_book()` переставляет блоки.
