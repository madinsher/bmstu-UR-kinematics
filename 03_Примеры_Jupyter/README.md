# Примеры к лекциям на Jupyter

Примеры написаны на небольшой библиотеке [`kinlib.py`](kinlib.py) и модулях занятий 4–7: [`trajlib.py`](trajlib.py), [`parallel.py`](parallel.py), [`wheeled.py`](wheeled.py), [`aerial.py`](aerial.py). Сами модули используют только `numpy`, `scipy` и `matplotlib`, чтобы каждую формулу лекции можно было найти в коде. Промышленная библиотека Robotics Toolbox for Python (`roboticstoolbox-python`) нужна только для сверок: в ноутбуках показано, что kinlib даёт те же матрицы, что и она, после учёта соглашений о порядке блоков.

Сквозной робот — UR5e с таблицей Денавита — Хартенберга производителя (`make_ur5e()`); плоские двух- и трёхзвенники служат «микроскопом», PUMA 560 — примером учебника. Обозначения в ноутбуках те же, что в конспекте (файл [`00_Паспорт/Обозначения.md`](../00_Паспорт/Обозначения.md)).

Запускайте ячейки сверху вниз; первая ячейка подключает `kinlib` и модуль занятия. Без `roboticstoolbox-python` ячейки сверки в ноутбуках 1, 2, 4–7 пропускаются, а ноутбук 3 этот пакет требует.

## Соглашения kinlib

Курс записывает скорость тела как $(\boldsymbol{\omega};\mathbf{v})$, как учебник и Линч — Парк. Метод `RobotSerial.jacobian` (и его синоним `jacobian_vw`) возвращает матрицу в порядке $[\mathbf{v};\ \boldsymbol{\omega}]$, как у Сицилиано, Корке и в Robotics Toolbox; метод `jacobian_book()` даёт порядок курса $(\boldsymbol{\omega};\mathbf{v})$. Линейная скорость в обоих случаях — скорость начала системы схвата в осях базы. Полная таблица соглашений библиотек — в лекции 3 (§ 3.3) и в разделе 3 файла обозначений.

Кватернион в `Frame.q_4` и `Frame.from_q_4` записывается в порядке пакета `scipy` — $(x, y, z, w)$, скалярная часть последней; в лекциях 1 и 7 скалярная часть стоит первой. Вектор поворота (`Frame.r_3`, `from_r_3`) — это ось, умноженная на угол в радианах, как в записи позы у UR.

## Что умеет kinlib

| Объект | Назначение |
|---|---|
| `Frame` | однородная матрица 4×4: произведение, обращение, построение по параметрам Денавита — Хартенберга (`from_dh`, `from_dh_modified`), по кватерниону (`from_q_4`), по вектору поворота (`from_r_3`); углы рыскания, тангажа и крена ZYX — `rpy_zyx` / `from_rpy_zyx` (старые имена `euler_3` / `from_euler_3` оставлены псевдонимами), углы Эйлера ZYZ — `euler_zyz` / `from_euler_zyz` |
| `RobotSerial(dh, joint_types='RRP…')` | разомкнутая цепь по таблице `d, a, alpha, theta0`; вращательные (`R`) и телескопические (`P`) сочленения; `forward`, `axis_frames`, `jacobian`, `jacobian_book`, `jacobian_vw`, `pose_error` |
| `RobotSerial.inverse_numerical` | численная обратная задача: методы `jac_pinv`, `jac_dls`, `jac_t`; полный шаг Ньютона с дроблением шага (`line_search=True`), раздельные допуски по положению и ориентации `tol_pos`, `tol_rot`, история невязок `inv_history` и принятых шагов `inv_steps`; при неудаче возвращается лучшее приближение; демпфирование — `dls_mu` (старое имя `dls_lambda` — псевдоним) |
| `RobotSerial.inverse_position` | обратная задача только по положению, тоже полный шаг с дроблением |
| `RobotTrajectory` | интерполяция между положениями в пространстве сочленений (`p2p`) и по прямой (`lin`); ориентация на прямой интерполируется по геодезической (SLERP) |
| `make_ur5e()`, `UR5E_DH` | UR5e по официальной таблице Universal Robots; у робота есть атрибуты `qlim`, `qd_max`, `reach` из паспорта |
| `make_puma(convention='rtb' \| 'book')`, `PUMA560_DH` | PUMA 560: таблица Robotics Toolbox или расстановка осей примера лекции 2 |
| `make_ur()`, `UR_DH` (`TRAINING_6R_DH`) | «учебный 6R» компоновки UR с условными размерами — для старых примеров и исходного ноутбука; это не модель конкретного робота |
| `so3_exp`, `so3_log`, `pose_error(T, T_des, order='vw' \| 'wv')` | экспонента и логарифм на SO(3); ошибка позы с точной ошибкой ориентации $\delta\boldsymbol{\varphi}=\log(R^{\ast}R^{\mathrm T})^{\vee}$ |
| `fk2r`, `ik2r`, `jac2r`, `fk_planar`, `jac_planar`, `draw_arm2d` | плоские двух- и многозвенники; у `ik2r` ветвь $q_2>0$ — «локоть вниз», $q_2<0$ — «локоть вверх» (оси x вправо, y вверх) |
| `workspace_2r`, `area_from_points`, `service_map_3r`, `service_coefficient_3r`, `service_average_3r` | рабочая зона и коэффициент сервиса |
| `skew`, `vee`, `jacobian_numeric` | кососимметрическая матрица $\Lambda(\boldsymbol{\omega})$ и численная проверка якобиана |
| `polygon_image`, `ellipse_image`, `sphere_radius`, `manipulability` | области допустимых скоростей и мера Йошикавы |
