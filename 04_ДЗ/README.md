# Домашние задания

В разделе «Кинематика» два домашних задания. Оба выполняются индивидуально, варианты различаются у каждого студента.

| | Задание | Что проверяет | Лекции | Результат |
|---|---|---|---|---|
| ДЗ1 | [Кинематика трёхзвенного манипулятора](ДЗ1_Кинематика_манипулятора/Задание.md) | системы координат Денавита — Хартенберга, прямую и обратную задачи о положении и о скорости | 1–3 | отчёт с выводом формул и численной проверкой |
| ДЗ2 | [Управление манипулятором в CoppeliaSim](ДЗ2_CoppeliaSim/Задание.md) | перенос кинематики в программу: модель робота в симуляторе, проверка рабочей зоны, движение по окружности через три точки | 2–4 | сцена, программа на Python, видео, отчёт |

## Как устроена работа

1. **Вариант.** Номер варианта ДЗ1 вычисляется по номеру группы и номеру в списке — формулы в задании, готовый калькулятор — [`variant.py`](ДЗ1_Кинематика_манипулятора/variant.py). Вариант ДЗ2 (робот и три точки) выдаёт преподаватель; правило выбора по умолчанию приведено в задании.
2. **Решение.** Порядок действий, типовые ошибки и приёмы самопроверки описаны в методике: [ДЗ1](ДЗ1_Кинематика_манипулятора/Методика_решения.md), [ДЗ2](ДЗ2_CoppeliaSim/Инструкция.md). Для ДЗ1 есть [полностью разобранный пример](ДЗ1_Кинематика_манипулятора/Пример_решения.md) на схеме, которой нет среди вариантов.
3. **Самопроверка.** Аналитические формулы ДЗ1 проверяются численно скриптом [`dz1_check.py`](ДЗ1_Кинематика_манипулятора/dz1_check.py): он строит манипулятор по вашей таблице Денавита — Хартенберга и сравнивает ваши формулы прямой задачи, обратной задачи и матрицы Якоби с расчётом библиотеки [`kinlib`](../03_Примеры_Jupyter/kinlib.py). Геометрия ДЗ2 проверяется без симулятора скриптом [`run_offline.py`](ДЗ2_CoppeliaSim/code/run_offline.py).
4. **Отчёт.** Оформляется по шаблону ([ДЗ1](ДЗ1_Кинематика_манипулятора/Шаблон_отчёта.md), [ДЗ2](ДЗ2_CoppeliaSim/Шаблон_отчёта.md)), сдаётся в PDF; к ДЗ2 прикладываются сцена, код и видео.

## Оценивание

| Критерий | ДЗ1 | ДЗ2 |
|---|---|---|
| Корректность результата (совпадение с численной проверкой, движение по заданной окружности) | 40 % | 40 % |
| Полнота вывода и обоснований (системы координат на схеме, все ветви решения, анализ особых конфигураций и достижимости) | 40 % | 30 % |
| Оформление, воспроизводимость (код запускается, рисунки подписаны, единицы указаны) | 20 % | 30 % |

Работа, в которой формулы не проверены численно (ДЗ1) или траектория не проверена на принадлежность рабочей зоне (ДЗ2), возвращается на доработку без оценки.

## Что нужно на компьютере

- Python 3.10+ с `numpy`, `scipy`, `matplotlib` — оба задания;
- Jupyter — по желанию, для экспериментов с [примерами к лекциям](../03_Примеры_Jupyter);
- [CoppeliaSim Edu](https://www.coppeliarobotics.com/) 4.5+ и пакет `coppeliasim-zmqremoteapi-client` — только для ДЗ2.
